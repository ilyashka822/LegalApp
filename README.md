# Премиальный корпоративный сайт для адвокатского кабинета

Полноценный многостраничный веб-ресурс, разработанный с нуля для практикующего адвоката. Главная бизнес-задача проекта — создать строгий, статусный и вызывающий доверие имидж специалиста, а также обеспечить удобный канал связи для новых клиентов.

## 🛠 Технологический стек
- **Backend:** C#, ASP.NET Core (Razor Pages)
- **Frontend:** HTML5, CSS3 (Flexbox/Grid, кастомная адаптивная верстка без использования тяжелых CSS-фреймворков)
- **Интеграции:** MailKit / MimeKit (защищенная отправка заявок с формы на email через SMTP)
- **Архитектура:** Использование Layout-шаблонов, маршрутизация, строгая типизация моделей данных, изоляция секретов приложения (User Secrets).

## 💡 Реализованный функционал
- Уникальный премиальный UI-дизайн (строгая цветовая палитра, типографика).
- Fully Responsive — полная адаптивность под любые устройства (мобильные телефоны, планшеты, десктопы).
- Интерактивное мобильное меню (JavaScript).
- Форма обратной связи на Backend-контроллере с валидацией данных.
- Плавный UX: микроанимации кнопок, плавная прокрутка, кнопка "Наверх".

## ⚙️ Запуск проекта на локальной машине
Для запуска проекта вам потребуется .NET 8.0 SDK (или новее) и Visual Studio 2022.
- Склонируйте репозиторий: git clone https://github.com/ilyashka822/LegalApp.git
- Перейдите в папку с проектом и откройте .sln файл в Visual Studio.
Важно для работы формы обратной связи: Настройте локальные секреты приложения. 
- Нажмите ПКМ по проекту -> Управление секретами пользователя и добавьте конфигурацию SMTP:{
  "Smtp": {
    "User": "your-email@gmail.com",
    "Password": "your-app-password",
    "To": "destination-email@gmail.com"
  }
}
- Запустите проект (F5).
